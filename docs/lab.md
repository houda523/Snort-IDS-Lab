# Snort IDS Lab

1. Use a host-only or otherwise isolated lab network.
2. Confirm the interface and ruleset for your installed Snort version.
3. Validate the configuration before starting IDS monitoring.
4. Generate a benign HTTP request to a local test server using `/portfolio-lab-test`.
5. Confirm the expected alert in Snort output or logs.
6. Record the timestamp, rule SID, expected behavior, and observed behavior.
7. Avoid collecting or publishing unrelated traffic or personal information.
